# CheatChat 서버🤖💬
---


CheatChat 서버는 llm을 통해 사용자 맞춤형 채팅 스타일로 답장을 추천해주는 채팅앱 플러그인입니다.


(Slack용과 일반 안드로인드 채팅앱에 적용 가능한 버전으로 구현했습니다.)




## 프로젝트 주요 기능🌟 


+ 사용자의 초기 설정 및 대화 맥락을 기반으로 사용자에게 최적화된 답장을 추천


+ 상대와의 누적 대화 내용에 기반하여 상대의 예상 답변 및 상대가 만족할만한 답장 생성


+ 직접 작성한 답장을 원하는 채팅 스타일(ex. 말투)로 변경 후 전송 가능



**대화가 쌓일수록 AI가 더욱 사용자의 채팅 스타일에 적합한 답장을 추천해주게 되는 구조 -> 사용할수록 더욱 사용자에게 최적화 및 개인화되는 시스템**
